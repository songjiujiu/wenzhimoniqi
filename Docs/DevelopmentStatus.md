# 开发进度 · 0.1.0 原型

日期：2026-09-20。基于 GDD v1.1，当前推进 M0–M2，并提前接入部分存档和设置能力。

## 已实现

- Unity 6.3 LTS 工程、URP、Input System、固定镜头场景及命令行构建入口。
- 50ms 固定 Tick；母蚊与虫卵分别使用排序时间桶；成蚊、虫卵和统计使用 BigInteger。
- 初始四只、1 秒产卵、半秒孵化、出生满 1 秒首产、小批量随机 / 大批量各半性别分配。
- 手掌、电拍和蚊香；独立冷却、本局峰值解锁、全局均匀击杀。
- 清场保留虫卵 deadline，同 Tick 先攻击后产卵和孵化，繁殖终止结算。
- 主菜单、HUD、武器选择、按住攻击、暂停、失焦处理、设置与本地纪录。
- 单槽存档、SHA-256 校验、备份恢复、逻辑 RNG 状态与完整 Tick 积欠持久化。
- Blender 蚊子源文件与 FBX：996 三角面，分材质合并后 GPU 实例绘制，最大 300 只代表。
- 首版程序搭建的房间、武器动作和自行合成的轻量音效。

## 已取得的验证结果

- Unity 工程初始化与 C# 编译成功。
- EditMode 自动测试 **28 / 28 通过**，包含 10^300 数量精度、孵化时序、随机恢复和损坏存档备份。
- 原始测试报告保存在本地 `TestResults/editmode.xml`，详细日志在 `Logs/tests.log`。
- Windows x64 独立程序构建成功，构建日志和摘要位于 `Logs/Build.log`、`TestResults/build-summary.txt`。
- Windows 实际运行验证通过：自然增长解锁三把武器，分别执行手掌、电拍、蚊香；暂停期间 Tick 不变；保存与恢复快照一致。
- 实际运行记录：[runtime-smoke.json](./Preview/runtime-smoke.json)。该验证通过正常命令入口执行攻击，不等同于已经测试所有物理键鼠组合。
- 已检查 [实际游戏画面](./Preview/gameplay.png)：中文 HUD、固定镜头房间、Blender 蚊子模型与三个武器状态均可显示。隐藏窗口采用显式 URP 渲染目标捕获，避免读取空白交换链。
- 当前机器上的一次 Tick 耗时只是运行记录，不作为 GDD 规定的 P95、60 FPS 或 30 分钟稳定性结论。
