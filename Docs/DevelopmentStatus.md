# 开发进度 · 0.1.3 原型

日期：2026-09-21。基于 GDD v1.1，当前推进 M0–M2，并提前接入部分存档和设置能力。

最新夜间场景：保持正面水平镜头；关闭日光，使用微弱冷色月光、暖色室内灯和台灯，点光源启用软阴影，窗外替换为夜景。蚊子及死亡模型同比缩至之前的 45%。原合成嗡鸣替换成 MarianaRA 的 CC0 真实蚊子录音，7.84 秒循环，保留原音高；少量成蚊即可播放，暂停、菜单、无成蚊和嗡鸣音量为零时停止。详见 `SourceArt/Audio/README.md`。

参考图资产已接入实际游戏：房间和家具源文件 `Room.blend` 保留 888 个独立部件、91,516 三角面及 21 个材质组；桌面蚊香移至独立资产。`ReferenceAssets.blend` 包含蚊子、手掌、电蚊拍、蚊香、招财猫及铁塔。房间和摆件已保存进 `Observatory.unity`，编辑模式即可看到；运行时复用场景对象，避免重复加载。手掌、电拍替换程序模型，蚊香触发桌面烟雾，翼脉与翅膜一起摆动。武器动画改为按结束时间计时，防止长帧吞掉新动作，并调整朝向以适应固定镜头。

写实化改进：木材、灰泥与织物改为 CC0 PBR 贴图，Unity 同时绑定颜色、法线和光滑度，木纹按构件方向展开。桌椅比例、弧形椅背、曲面叶片、窗洞和书页边缘已更新；窗外使用单独生成的远景图片。开启软阴影、SSAO 接触阴影、房间反射和 ACES 调色，使用统一的 `StudyLighting` 配置替换蓝色点光。桌上独立摆件与灯光随桌面高度同步调整。`ReferenceSceneSetup.Prepare` 现在重新导入生成子对象，解决旧场景一直复用过时材质的问题；编辑器菜单为 `Mosquito/刷新书房模型与材质`。素材来源和图片提示词见 `SourceArt/TextureSources.md`。

**62 / 62 项 EditMode 测试通过，1 / 1 项 PlayMode 显示集成测试通过。** PlayMode 测试加载正式场景，在隔离存档下检查模型、相机、虫卵以及三类武器反馈，保存 `Docs/Preview/reference-*.png`。该测试验证运行时模型与反馈路径，不等于完成手动输入、性能或全部玩法验收。未构建游戏和安装包。通过 `Tools/OpenGame.cmd` 打开正确工程；现有 0.1.2 安装包仍为旧版本。

最新源码规则优先于下方版本历史：产卵间隔 6 秒、孵化 3 秒、出生满 6 秒首次产卵；旧存档等待时间按比例迁移。手掌在瞄准范围内必中，点击空白处不击杀；独立随机转向和变速替代固定轨迹，暂停也会暂停飞行。按用户要求，本次不构建游戏或安装包，飞行动作仍需在 Unity 中实际试玩确认。

虫卵显示新增 `SurfaceEggView`：仅在实际地板顶面及墙壁内侧面取随机点，按表面法线放置扁卵模型，底部与实体表面相切。稳定保留尚未孵化批次的位置，按真实孵化 deadline 移除；清场不删除虫卵。最多 300 个可视代表，不改变逻辑数量和 RNG。找不到有效表面时跳过显示，没有空中位置回退。

手掌新增虫卵目标：与成蚊一起按指针距离选择最近的单个目标，命中后立即移除对应显示和孵化桶中的 1 枚卵。成蚊和虫卵共用手掌冷却；没有成蚊时仍可消灭虫卵，最后一枚卵被击碎且无母蚊时结束繁殖。新增持久化 `eggsKilled` 计数并更新数量守恒校验；旧存档缺失该字段时按 0 读取。成蚊累计击杀数不包含虫卵。
